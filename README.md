# Budget App

An Object-Oriented Python application designed to track expenses across different categories (such as food, clothing, and entertainment) and visualize spending patterns using an ASCII bar chart. Built for the **freeCodeCamp Scientific Computing with Python** certification.

## 🛠️ Features

* **Category Management:** Create individual budget categories with isolated ledgers.
* **Financial Operations:** Deposit, withdraw, and transfer funds between categories with automatic ledger logging.
* **Balance Verification:** Built-in checks (`check_funds`) to prevent overdrafting.
* **Formatted Output:** Custom string representation (`__str__`) for clean receipt-like balance prints.
* **Spending Visualization:** `create_spend_chart` generates an ASCII percentage chart of expenses across categories.

## 💻 Tech Stack

* **Language:** Python 3 (Object-Oriented Programming)
